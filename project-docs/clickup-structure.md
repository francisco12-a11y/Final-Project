# FP | Francisco Buiras | Lead Magnet Launch — ClickUp breakdown

Build this in ClickUp in about 10 minutes. Deadline everything works backwards from:
**Wednesday, October 7, 2026, end of day (submission closes).**

## How to build it fast

1. Create a List named **FP | Francisco Buiras | Lead Magnet Launch** (inside a Space called FP | Francisco Buiras).
2. Fastest path: import `lead-magnet-launch.csv` from this folder (List → Import → CSV). Map columns: Name, Status, Priority, Due Date, Description. Subtasks arrive as checklist items inside each task's description — split them into real subtasks for 3 or 4 key tasks only (the judges want to see nesting, not everywhere).
3. Or build by hand using the structure below. Convert the 7 milestone rows into Milestone tasks (task type → Milestone) with the same due dates.
4. Owners: assign Fran = you, ZCode = add as a guest/teammate, or use two statuses. Every task gets an owner either way.
5. Add two custom fields: `Link index item` (L1–L15, H1–H9) and `Asset URL`. Paste the link from the table in this file into each task — the board then doubles as your link index.
